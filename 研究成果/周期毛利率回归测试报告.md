> **测试日期：** 2026-10-03
> **测试目标：** 使用与牛市推导完全相同的公式，验证非牛市（F₀ < 20,000元/吨）实际数据下的周期毛利率
> **数据区间：** 2020-06 ~ 2026-09（995个库存周期窗口）
> **测试结果：** 非牛市周期毛利率范围 -1.27% ~ 12.00%

---

## 1. 测试背景

### 1.1 为什么要做回归测试？

在之前的分析中，我们基于牛市背景（F₀ ≥ 20,000元/吨）理论推导了初加工的周期毛利率，得出**0.72% ~ 21.11%**的完整区间。

但实际数据中，**过往价格从未站稳2万点以上**（最高约19,645元/吨），全部属于非牛市环境。

**需要验证**：
1. 我们的计算方法在非牛市实际数据上是否合理？
2. 非牛市环境下的实际毛利率是多少？
3. 非牛市与牛市的毛利率差异有多大？是否符合经济逻辑？

### 1.2 测试方法

**核心公式**（与牛市推导完全一致）：
```
R_avg = (R₀ + R₁) / 2
周期总利润 = (F₁ - 基差) - (R_avg×1000 + 采购溢价) - 加工成本
周期毛利率 = 周期总利润 / ((F₀+F₁)/2 - 基差)

参数：
- 基差 = 800元/吨
- 采购溢价 = 500元/吨
- 加工成本 = 1,200元/吨
```

**测试步骤**：
1. 从995个库存周期窗口中，筛选出非牛市窗口（F₀ < 20,000元/吨）
2. 按涨跌幅分类为8种场景（上涨5种 + 下跌3种）
3. 使用相同的公式计算各场景的周期毛利率
4. 与牛市理论推导值对比

> **实际报告毛利率（~2%）不是"上限"，而是"平均/较差情况"。**
>
> - 非牛市下跌场景毛利率（-1.27% ~ 1.19%）与实际报告值高度吻合
> - 上涨场景的毛利率（6-12%）显著高于实际报告值
> - **通过优化运营，有潜力将毛利率提升至6-12%**
>
> **投资启示**：
> 1. 不要用实际报告毛利率低估盈利潜力
> 2. 关注库存周期的涨跌方向，对毛利率预期至关重要
> 3. 优化库存管理和期现套利能力，是提升毛利率的关键

## 附录：回归测试详细计算过程

### 场景 D_12-18%上涨 详细验证（非牛市实际数据）

**输入数据**（中位数）：
- F₀ = 14,135元/吨
- R₀ = 11.89元/kg
- F涨幅 = +15.75%
- R涨幅 = +4.83%
- G = -9.67pp

**计算过程**：
```
Step 1: 计算F₁
F₁ = F₀ × (1 + F涨幅) = 14,135 × 1.1575 = 16,361元/吨

Step 2: 计算R₁
R₁ = R₀ × (1 + R涨幅) = 11.89 × 1.0483 = 12.46元/kg

Step 3: 计算R_avg
R_avg = (R₀ + R₁) / 2 = (11.89 + 12.46) / 2 = 12.18元/kg

Step 4: 计算平均售价
平均售价 = (F₀ + F₁)/2 - 基差 = (14,135 + 16,361)/2 - 800 = 15,248 - 800 = 14,448元/吨

Step 5: 计算周期总利润
周期总利润 = (F₁ - 基差) - (R_avg×1000 + 采购溢价) - 加工成本
           = (16,361 - 800) - (12.18×1000 + 500) - 1,200
           = 15,561 - 12,680 - 1,200
           = 1,681元/吨

Step 6: 计算周期毛利率
周期毛利率 = 周期总利润 / 平均售价 × 100% = 1,681 / 14,448 × 100% = 11.63%
```

**验证结果**：
- 计算值：11.63%（中位数统计值为12.00%，差异来自中位数计算的精度）
- 牛市理论值：20.60%
- 差异：-8.97pp（-43.5%）
- **结论**：非牛市毛利率显著低于牛市理论值，符合经济逻辑

**文档说明**：本报告基于2020-06至2026-09期间的995个库存周期窗口数据，使用与牛市推导完全相同的周期毛利率公式，对非牛市（F₀ < 20,000元/吨）实际数据进行回归测试。测试结果验证了计算方法的合理性，非牛市毛利率范围为-1.27% ~ 12.00%，普遍低于牛市理论推导值（0.72% ~ 21.11%），符合期现非对称性的经济逻辑。
