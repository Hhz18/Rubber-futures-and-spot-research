# 海南橡胶初加工毛利率研究过程总结

> **研究时间**：2026年9-10月
> **研究主题**：海南橡胶初加工毛利率在牛市/非牛市中的变化规律
> **文档性质**：研究过程简易总结（已更新最新进展）

---

## 一句话概括

从"初加工毛利率由什么决定"出发，经过9个研究节点，最终得出：**牛市毛利率0.72%~21.11%，非牛市-1.27%~12.00%，实际报告值~2%反映的是"平均/较差情况"**。

---

## 研究过程（9个节点）

### 节点1：毛利率由什么决定？

**讨论内容**：海南橡胶初加工业务的毛利率受哪些因素影响？

**核心发现**：
- 期货价格（售价锚点）
- 原料成本（全省均价 × 1000）
- 加工成本（约800元/吨）
- 基差（期货与现货的价差）

---

### 节点2：牛市中毛利率能到多少？

**讨论内容**：分析五种涨幅场景（3-5%、5-7%、≈10%、15%、20%）下的毛利率

**产出**：创建《海南橡胶初加工毛利率分析.md》

**初步结果**：用旧公式算出毛利率10-20%

---

### 节点3：为什么算出来和实际不一样？

**发现问题**：计算值(10-20%)与实际报告(~2%)差距巨大！

**找到五大原因**：
1. **基差问题**：期货长期升水500-1500元/吨，实际售价 < 期货价
2. **采购溢价**：实际采购价高于全省均价约500元/吨
3. **隐性成本**：加工成本需从800上修至1200元/吨
4. **产品折价**：非交割品（浓乳、杂胶）低于期货价
5. **产能利用率**：仅53%，固定成本摊薄不足

**产出**：创建《初加工毛利率差异分析.md》

---

### 节点4：修正计算方法

**修正参数**：
- 基差：800元/吨
- 采购溢价：500元/吨
- 加工成本：1,200元/吨

**操作**：重写了所有文档，删除旧的计算方法

---

### 节点5：发现公式有重复计算问题

**用户指出**："有效毛利率"公式把dS重复加了！

**问题分析**：
```
起点加工利润 + dS = 终点加工利润（概念混淆！）
```

**修正方案**：提出周期毛利率公式（R_avg均价成本法）

**核心公式**：
```
R_avg = (R₀ + R₁) / 2
周期总利润 = (F₁ - 基差) - (R_avg×1000 + 采购溢价) - 加工成本
周期毛利率 = 周期总利润 / ((F₀+F₁)/2 - 基差)
```

**关键点**：dS不用于计算，仅用于解释差异来源

---

### 节点6：牛市理论推导

**背景**：实际数据中价格≥2万的样本极少，需要理论推导

**假设条件**：
- 牛市起点：F₀ = 20,000元/吨
- 原料起点价：R₀ = 15.88元/kg（基于历史比例）
- 参数：基差800 + 溢价500 + 加工成本1200

**推导结果**：牛市毛利率区间 **0.72% ~ 21.11%**

**产出**：创建《牛市初加工毛利率推导分析.md》

---

### 节点7：补充下跌场景

**用户要求**：补充下跌场景，确定毛利率的最终下限

**补充场景**：
- F_3-5%下跌：6.31%
- G_5-7%下跌：4.07%
- H_8-10%下跌：**0.72%**（最终下限）

**完整牛市区间**：0.72% ~ 21.11%（波动幅度20.39个百分点）

---

### 节点8：回归测试验证

**用户要求**：用相同算法测试过往非牛市数据，验证方法合理性

**测试条件**：
- 数据：2020-06 ~ 2026-09，995个库存周期窗口
- 筛选：全部为非牛市（F₀ < 20,000元/吨）
- 公式：与牛市推导完全一致

**测试结果**：非牛市毛利率 **-1.27% ~ 12.00%**

**⭐ 最重要发现**：
| 场景类型 | 非牛市毛利率 | 实际报告值 | 对比 |
|---------|------------|-----------|------|
| 上涨场景 | 6.49% ~ 12.00% | ~2% | 显著高于 |
| **下跌场景** | **-1.27% ~ 1.19%** | **~2%** | **最为接近！** |

**核心结论**：实际报告毛利率(~2%)反映的是"平均情况"或"较差情况"

**产出**：创建《周期毛利率回归测试报告.md》

### 节点9：利润计算

**用户问题**：如何计算牛市中23.85万吨的利润？

**计算公式**：
```
总利润 = 周期总利润（元/吨） × 23.85万吨
```

**牛市利润区间**（基于23.85万吨）：
- 上限：10.62亿元/周期（E场景 ≥18%涨幅）
- 中位数：7.57亿元/周期（C场景 8-12%涨幅）
- 最终下限：0.31亿元/周期（H场景 8-10%跌幅）

```
R_avg = (R₀ + R₁) / 2
周期总利润 = (F₁ - 800) - (R_avg×1000 + 500) - 1200
周期毛利率 = 周期总利润 / ((F₀+F₁)/2 - 800)
总利润 = 周期总利润 × 23.85万吨
```

## 推导过程（新增）

### 为什么要进行推导？

1. **数据稀缺**：过往数据中期货价格从未站稳2万点以上（最高约19,645元/吨），无法直接分析牛市毛利率
2. **传导规律**：从历史数据中提取原料(R)与期货(F)的传导规律（G = R% - F%）
3. **理论推导**：假设牛市起点，应用传导规律推算各场景下的期末价格
4. **回归验证**：用相同公式测试非牛市实际数据，验证方法合理性

### 推导流程（以C场景为例）

```
Step 1: 确定输入参数
  - F₀ = 20,000元/吨（牛市起点）
  - R₀ = 15.88元/kg（基于历史比例）
  - C场景历史传导规律：G中位 = -4.58pp

Step 2: 推算期末价格
  - F涨幅 = +9.87%（C场景中位数）
  - F₁ = 20,000 × 1.0987 = 21,974元/吨
  - R涨幅 = F涨幅 + G = 9.87% - 4.58% = 5.29%
  - R₁ = 15.88 × 1.0529 = 16.72元/kg

Step 3: 计算周期平均成本
  - R_avg = (15.88 + 16.72) / 2 = 16.30元/kg
  - 平均售价 = (20,000 + 21,974)/2 - 800 = 20,187元/吨

Step 4: 计算周期总利润
  - 周期总利润 = (21,974 - 800) - (16.30×1000 + 500) - 1200
              = 21,174 - 16,800 - 1200
              = 3,174元/吨

Step 5: 计算周期毛利率
  - 周期毛利率 = 3,174 / 20,187 × 100% = 15.72%
  - 总利润 = 3,174 × 23.85万吨 = 7.57亿元
```

### 关键洞察

> **为什么C场景毛利率(15.72%)高于A场景(12.39%)？**
>
> 因为涨幅越大，原料滞后越明显（G越负），期现价差红利越大。

## 投资启示

1. **不要用实际报告毛利率低估潜力**
   - 实际报告值反映的是"平均/较差情况"
   - 上涨周期的毛利率可达6-12%

2. **关注库存周期的涨跌方向**
   - 涨跌导致毛利率差异超过13个百分点
   - 判断周期方向对毛利率预期至关重要

3. **牛市潜力更大，但风险也更高**
   - 牛市区间：0.72% ~ 21.11%（波动20.39pp）
   - 非牛市区间：-1.27% ~ 12.00%（波动13.27pp）
