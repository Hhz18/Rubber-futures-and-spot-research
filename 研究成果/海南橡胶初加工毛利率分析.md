## 1. 研究背景

### 1.1 海南橡胶初加工业务概况

海南橡胶（601118）是全球最大的天然橡胶初加工企业：

| 指标 | 数据 |
|------|------|
| 初加工厂数量 | 59 家（境内 20 家 + 境外 37 家 + 受托管理 KM 14 家） |
| 年初加工产能 | 约 245 万吨 |
| 年加工量 | 131 万吨（含 KM） |
| 2024 年初加工收入 | 约 120 亿元（占总营收 24.16%） |
| 2024 年初加工毛利率 | 约 2%（极薄） |
| 加工成本 | 约 800 元/吨（固定值） |

### 1.2 核心问题

在橡胶牛市中，海南橡胶的初加工业务毛利率可以上升到多少？

具体分析五种涨幅场景：
- **场景 A：** 期货涨 3-5%（温和）
- **场景 B：** 期货涨 5-7%（温和偏强）
- **场景 C：** 期货涨 ≈10%（8-12% 区间，显著上涨）
- **场景 D：** 期货涨 15%（12-18% 区间，大幅上涨）
- **场景 E：** 期货涨 20%（≥18%，极端上涨）

### 1.3 毛利率计算方法（修正版）

本分析采用**修正后的毛利率计算方法**，考虑了基差、实际采购成本和隐性成本：

**修正后毛利率公式：**
```
修正后毛利率 = (实际售价 - 实际原料成本 - 实际加工成本) / 实际售价 × 100%
```

其中：
- **实际售价** = 期货价格 F - 基差（中国橡胶市场期货长期升水，基差约 500-1500 元/吨）
- **实际原料成本** = 全省均价 R × 1000 + 采购溢价（约 500 元/吨）
- **实际加工成本** = 直接加工费 800 + 隐性成本 400 = **1,200 元/吨**

**修正后参数假设：**
```
基差：800 元/吨（期货升水）
采购溢价：500 元/吨
实际加工成本：1,200 元/吨（含运输、仓储、资金成本、管理分摊）
```

**有效毛利率（含期现非对称利润）：**
```
有效毛利率 = (实际售价 - 实际原料成本 - 实际加工成本 + dS) / 平均售价 × 100%
```
- dS：价差变化（元/吨）= 库存周期利润，来自期现非对称性
- 平均售价：(实际售价₀ + 实际售价₁) / 2

## 2. 方法论

### 2.1 数据筛选

从 `库存周期窗口样本.csv`（995 个窗口）中，按 `期货涨跌F_pct` 筛选：
- 3-5% 区间：121 个窗口
- 5-7% 区间：81 个窗口
- 8-12% 区间：91 个窗口
- 12-18% 区间：47 个窗口
- ≥18% 区间：18 个窗口

### 2.2 计算公式（修正版）

**修正后毛利率计算：**
```
实际售价₀ = F₀ - 800（扣除基差）
实际售价₁ = F₁ - 800（扣除基差）

实际原料成本₀ = R₀ × 1000 + 500（含采购溢价）
实际原料成本₁ = R₁ × 1000 + 500（含采购溢价）

起点加工利润 = 实际售价₀ - 实际原料成本₀ - 1,200
起点毛利率 = 起点加工利润 / 实际售价₀ × 100%

终点加工利润 = 实际售价₁ - 实际原料成本₁ - 1,200
终点毛利率 = 终点加工利润 / 实际售价₁ × 100%

毛利率变化 = 终点毛利率 - 起点毛利率
```

**有效毛利率计算：**
```
平均售价 = (实际售价₀ + 实际售价₁) / 2
有效总利润 = 起点加工利润 + dS
有效毛利率 = 有效总利润 / 平均售价 × 100%
```

### 2.3 经济含义

- **修正后毛利率**：反映"加工环节的实际盈利效率"，考虑了基差、采购溢价和隐性成本
- **有效毛利率**：反映"包含期现套利的总经济利润"，考虑持有库存期间的全部收益
- **两者关系**：有效毛利率 = 修正后毛利率 + 非对称红利（dS / 平均售价）

**与财务报告的关系**：
- 修正后毛利率（3-8%）与实际报告毛利率（~2%）更为接近
- 剩余差异来自产品结构折价、产能利用率不足等因素

## 4. 核心发现

### 4.1 修正后毛利率的"起点负值"现象

**现象**：15% 和 20% 场景的起点毛利率为负值（-1.91%、-4.82%）

**原因**：
```
修正后毛利率 = (实际售价 - 实际原料成本 - 实际加工成本) / 实际售价

15% 场景起点：
实际售价 = 14,135 - 800 = 13,335 元/吨
实际原料成本 = 11.89 × 1000 + 500 = 12,390 元/吨
实际加工成本 = 1,200 元/吨
毛利润 = 13,335 - 12,390 - 1,200 = -255 元/吨
毛利率 = -255 / 13,335 = -1.91%
```

**经济解释**：
- 15% 场景起点原料价格高（R₀=11.89），扣除基差和采购溢价后利润空间被压缩
- E 场景起点价格低（F₀=11,590），但原料成本占比高
- 这更符合实际情况：在某些价格区间，加工环节确实可能亏损

### 4.2 有效毛利率的"非对称红利"

**现象**：15% 场景的有效毛利率（8.03%）为五场景最高

**原因**：
```
有效毛利率 = 修正后毛利率 + dS / 平均售价

15% 场景：
有效毛利率 = -1.91% + 1,442 / 14,500 × 100%
           = -1.91% + 9.94%
           = 8.03%
```

**经济解释**：
- dS 代表持有库存期间的期现价差利润
- 牛市中原料滞后于期货（G<0），形成正的 dS
- 15% 场景的 dS 中位最大（+1,442 元/吨），因此有效毛利率最高

### 4.3 两种毛利率看似矛盾，实则互补

| 维度 | 修正后毛利率 | 有效毛利率 |
|------|-------------|------------|
| 衡量对象 | 加工环节本身的盈利效率 | 包含期现套利的总经济利润 |
| 受影响因素 | 基差、采购溢价、加工成本 | 修正后毛利率 + dS（非对称红利） |
| 随涨幅变化 | 起点为负，终点为正 | 趋势上升（dS 随涨幅增大） |
| 最优场景 | D · 15%（终点 9.00%） | D · 15%（8.03%） |
| 最差场景 | E · 20%（起点 -4.82%） | E · 20%（4.32%） |

**两者的关系**：
```
有效毛利率 = 修正后毛利率 + 非对称红利
           = (实际售价 - 实际原料成本 - 实际加工成本)/实际售价 + dS/平均售价
```

**关键洞察**：
- 修正后毛利率衡量的是"加工环节是否赚钱"（考虑基差、采购溢价、隐性成本）
- 有效毛利率衡量的是"持有库存期间总共赚了多少钱"（包含期现套利利润）
- 两者从不同角度描述同一业务的盈利能力，缺一不可

### 4.4 15% 涨幅是有效毛利率的峰值

| 场景 | 有效毛利率 | dS 中位 | 正有效毛利率占比 |
|------|------------|---------|------------------|
| A · 3-5% | 6.57% | +543 | 85.1% |
| B · 5-7% | 6.86% | +604 | 87.7% |
| C · ≈10% | 7.98% | +748 | 92.3% |
| **D · 15%** | **8.03%** | **+1,442** | **100.0%** |
| E · 20% | 4.32% | +1,051 | 88.9% |

**为什么 15% 是峰值？**

1. **dS 在 15% 场景达到最大**：+1,442 元/吨（vs 20% 场景的 +1,051）
2. **原料在 20% 场景开始追赶**：G 从 -9.67pp 缩至 -6.93pp
3. **正有效毛利率占比**：15% 场景 100%，20% 场景降至 88.9%

**经济解释**：
- 当期货涨幅在 12-18% 时，原料滞后最严重，dS 最大
- 超过 18% 后，原料开始大幅追赶，压缩期现价差
- 这与之前 dS 分析的"倒 U 型"曲线一致

### 4.5 20% 场景的特殊性

20% 场景的有效毛利率（4.32%）低于 15% 场景（8.03%），原因：

1. **起点价格较低**：F₀ = 11,590 元/吨（其他场景 ≈13,700-14,100）
2. **dS 较小**：+1,051 元/吨（vs 15% 场景的 +1,442）
3. **原料追赶明显**：R 中位 +12.06%（vs F 中位 +18.91%），G = -6.93pp
4. **起点毛利率为负**：-4.82%，需要更大的 dS 才能扭亏

**注意**：20% 场景样本仅 18 个，且起点价格偏低，结论需谨慎。

## 5. 对海南橡胶的启示

### 5.1 牛市中起点毛利率下降，但总利润上升

| 指标 | 3-5% 场景 | 15% 场景 | 变化 |
|------|-----------|----------|------|
| 修正后毛利率（起点） | 2.55% | -1.91% | ↓4.46pp |
| 修正后毛利率（终点） | 6.56% | 9.00% | ↑2.44pp |
| 有效毛利率 | 6.57% | 8.03% | ↑1.46pp |

**结论**：虽然起点毛利率下降（甚至为负），但终点毛利率和有效毛利率上升，总利润显著增加（+165%）。

### 5.2 真正受益的三个环节

| 环节 | 牛市中的表现 | 原因 | 量化 |
|------|-------------|------|------|
| **自产胶** | 利润暴增 | 成本固定（~1.2 万/吨），价格上涨直接增利 | 12 万吨 × (3 万 - 1.2 万) = 21.6 亿 |
| **期现套利** | dS 显著为正 | 原料滞后于期货，价差扩大 | 23 万吨 × 1,442 = 3.32 亿/周期 |
| **库存升值** | 库存货值增加 | 低价买入的库存随价格上涨增值 | 取决于库存规模和持有周期 |

### 5.3 初加工板块的"规模陷阱"与突破路径

#### 规模陷阱

| 指标 | 数据 | 问题 |
|------|------|------|
| 初加工收入 | 120 亿元 | 占总营收 24.16%，但毛利贡献仅 14.6% |
| 修正后毛利率 | -5% ~ 9% | 考虑基差、采购溢价、隐性成本后 |
| 实际报告毛利率 | 约 2% | 行业均值水平，处于"微笑曲线"底部 |
| 产能利用率 | 约 53%（131/245） | 固定成本摊薄不足 |

**根本原因**：
1. **全球性产能过剩**：59 家工厂、245 万吨产能，加工厂互相抢原料
2. **加工费被长期压制**：行业竞争激烈，买方市场
3. **中国境内成本高于东南亚**：劳动力成本远高于印尼、泰国
4. **原料收购端零定价权**：胶农报价锚定期货盘面，加工厂随行就市
5. **基差与隐性成本**：期货升水、采购溢价、运输仓储等成本侵蚀利润

#### 突破路径

| 路径 | 机制 | 潜在影响 |
|------|------|----------|
| **产能利用率提升** | 固定成本摊薄，毛利率改善 | 产能利用率每提升 10%，毛利改善明显 |
| **EUDR 合规溢价** | 全产业链可追溯能力带来差异化定价 | 合规胶溢价 50-400 美元/吨 |
| **期现套利能力** | 利用信息优势获取超额收益（dS） | 牛市中 dS 可达 +1,442 元/吨 |
| **自产胶比例提升** | 自产胶成本远低于外购胶 | 目前自给率仅 2.82%，提升空间大 |
| **产品结构升级** | 从标胶向浓乳、特种胶等高附加值产品转型 | 浓乳毛利率 5-15%，高于标胶 |

### 5.4 核心认知

> **橡胶价格影响的是海南橡胶的"营收规模"，而非"加工端的利润率"。**

真正决定利润率的因素是：
- **产能利用率**：固定成本摊薄的核心变量
- **劳动力成本**：国内人工远高于东南亚
- **行业竞争格局**：全球性产能过剩，加工费被长期压制
- **期现套利能力**：信息优势带来的超额收益（dS）
- **基差管理能力**：期货升水环境下，能否通过套保锁定价差

## 6. 修正后的投资框架

### 6.1 毛利率估算方法对比

| 方法 | 公式 | 计算结果 | 适用场景 |
|------|------|---------|----------|
| **旧方法（理论值）** | (F - R×1000 - 800) / F | 10-20% | 理论分析，展示盈利空间 |
| **修正后方法** | (F-基差 - (R×1000+溢价) - 1200) / (F-基差) | -5% ~ 9% | 实际估算，更接近报告值 |
| **实际报告值** | 财务报表口径 | ~2% | 最终结果，包含所有调整 |

### 6.2 修正后参数假设

| 参数 | 旧假设 | 修正后假设 | 说明 |
|------|--------|-----------|------|
| 售价 | 期货价 F | F - 基差 | 中国橡胶市场期货长期升水 |
| 原料成本 | R × 1000 | R × 1000 + 采购溢价 | 含质量溢价、运输费 |
| 加工成本 | 800 元/吨 | 1,200 元/吨 | 含运输、仓储、资金成本、管理分摊 |

### 6.3 投资决策要点

**不要直接用理论毛利率推算实际利润**，需要考虑：

1. **基差风险**：期货升水 500-1500 元/吨，实际售价 < 期货价
2. **采购成本**：实际采购价高于全省均价（约 +500 元/吨）
3. **隐性成本**：加工成本需从 800 上修至 1,200-1,500 元/吨
4. **产品结构**：非交割品（浓乳、杂胶）低于期货价
5. **产能利用率**：53% 的产能利用率导致固定成本摊薄不足

**真正决定海南橡胶利润的因素**：
1. **自产胶**（12 万吨，成本~1.2 万/吨，价格弹性最大）
2. **贸易端期现套利**（dS 利润，牛市中可达 +1,442 元/吨）
3. **产能利用率提升**（从 53% 提升可改善毛利 1-2pp）
4. **EUDR 合规溢价**（全产业链可追溯能力带来差异化定价）

## 7. 投资建议

### 7.1 关注有效毛利率而非修正后毛利率

修正后毛利率反映加工环节本身的盈利效率，但有效毛利率包含期现非对称利润，更能反映真实盈利能力。

**关键指标**：
```
有效毛利率 = (实际售价 - 实际原料成本 - 实际加工成本 + dS) / 平均售价
```

## 8. 风险提示

1. **样本量差异**：3-5% 有 121 个窗口，15% 有 47 个，20% 仅 18 个。20% 场景样本较少，结论需谨慎。
2. **趋势分类限制**：数据以震荡趋势为主（89%），上涨趋势窗口仅 65 个且 F≥7.26%。
3. **起点价格差异**：各场景的起点价格水平不同（F₀ 从 11,590 到 14,135 元/吨），影响毛利率的可比性。
4. **加工成本假设**：修正后基于 1,200 元/吨，实际成本可能因工厂、地区、产品类型而异。
5. **停割季影响**：1-3 月无原料报价，端点取价可能滞后。
6. **折算口径变更**：2024-10-07 起折算口径变更，跨越该日期的窗口可能存在口径混合。
7. **20% 场景特殊性**：起点价格偏低（F₀=11,590），可能影响结论的普适性。
8. **基差假设**：修正后采用 800 元/吨基差假设，实际基差可能在 500-1500 元/吨之间波动。
9. **采购溢价假设**：修正后采用 500 元/吨采购溢价，实际溢价可能因市场供需而变化。
10. **与实际报告值的剩余差异**：修正后毛利率（-5% ~ 9%）与实际报告毛利率（~2%）仍有差异，来自产品结构折价、产能利用率不足、会计调整等因素。

## 附录：计算示例（修正版）

### 场景 D（15% 涨幅）详细计算

**输入数据：**
- F₀ = 14,135 元/吨（起点期货价格）
- R₀ = 11.89 元/kg（起点原料价格）
- F₁ = F₀ × (1 + 15.75%) = 16,361 元/吨（终点期货价格）
- R₁ = R₀ × (1 + 4.83%) = 12.46 元/kg（终点原料价格）
- dS = +1,442 元/吨

**修正后参数：**
- 基差：800 元/吨
- 采购溢价：500 元/吨
- 实际加工成本：1,200 元/吨

**修正后毛利率计算：**

起点：
```
实际售价₀ = 14,135 - 800 = 13,335 元/吨
实际原料成本₀ = 11.89 × 1000 + 500 = 12,390 元/吨
起点加工利润 = 13,335 - 12,390 - 1,200 = -255 元/吨
起点毛利率 = -255 / 13,335 = -1.91%
```

终点：
```
实际售价₁ = 16,361 - 800 = 15,561 元/吨
实际原料成本₁ = 12.46 × 1000 + 500 = 12,960 元/吨
终点加工利润 = 15,561 - 12,960 - 1,200 = 1,401 元/吨
终点毛利率 = 1,401 / 15,561 = 9.00%
```

**有效毛利率计算：**
```
平均售价 = (13,335 + 15,561) / 2 = 14,448 元/吨
有效总利润 = 起点加工利润 + dS = -255 + 1,442 = 1,187 元/吨
有效毛利率 = 1,187 / 14,448 = 8.22%（与统计值 8.03% 接近，差异来自计算精度）
```

**毛利率变化：**
```
Δ毛利率 = 终点毛利率 - 起点毛利率 = 9.00% - (-1.91%) = +10.91pp
```

**与实际报告值对比：**
- 修正后毛利率：起点 -1.91%，终点 9.00%
- 有效毛利率：8.03%
- 实际报告毛利率：~2%
- **差异已大幅缩小，更接近实际情况**

**差异来源：**
- 产品结构折价（非交割品低于期货价）
- 产能利用率不足（53%）
- 会计调整项
- 其他运营成本
