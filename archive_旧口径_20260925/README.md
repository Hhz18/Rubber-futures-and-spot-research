# 归档说明 · 旧口径（2026-09-25）

本目录存放**已废弃**的脚本、数据产物、报告与图表。保留的唯一目的是可追溯，
**不要再用其中的任何结论**。

---

## 为什么废弃

2026-09-25 的数据审计发现三件事，导致旧口径的结论数字全部需要重算：

1. **构成污染**：旧口径的原料"全省均价"= 当期**有报价**市县的简单均值，
   报价市县数在 1~18 浮动（63.1% 的期非全覆盖），逐期构成效应最大 18.53pp。
2. **`A = R / F` 已被禁用**：分母爆炸（`|F|→0` 时发散）、代数伪影
   （截距为负必然造出"上涨侧低、下跌侧高"）、无基准（涨2-5%档的
   `A<1 占比` 落在随机配对安慰剂区间内）。详见 `新研究_口径定义书.md` 第四节。
3. **样本量虚高**：滑动窗口逐日推进，同一行情片段生成几十个窗口。
   "7 天涨15%档 n=7"实为 **1 个事件**；"15 天涨20%档 n=9"实为 **2 个事件**。

新口径见 `数据审计与清洗报告.md`，管线是
`audit_data_source.py` + `clean_provincial_price.py` + `micro_windows_provincial.py`
（统一入口 `audit_and_clean_data.py`）。

## 想恢复某个文件

所有归档文件都是**移入**而非删除，`mv archive_旧口径_20260925/旧脚本/xxx.py .`
即可拿回。但请注意：

- `build_price_index.py`、`make_charts.py` 恢复后仍会因缺 `收购价_城市矩阵.csv` /
  `收购价_可比指数.csv` 而报错，需一并从 `旧数据产物/` 恢复对应 CSV；
- `analyze_micro_*.py` 恢复后可运行（它们经 `build_dataset.load_cities()` 取数，
  而该函数现已改从 `data/raw/` 解析），但结论仍是旧口径。
